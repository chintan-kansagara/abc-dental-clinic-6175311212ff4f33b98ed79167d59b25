# Business website
Generated by SiteForge from a structured business plan. Edit `src/site.json` for copy and section ordering, `src/main.jsx` for components, and `src/styles.css` for design. Install Node 24, then run `npm ci`, `npm run dev`, or `npm run build`. Deploy the `dist` directory to a static host. This demo deliberately uses noindex; remove it only after client approval. Missing verified facts are omitted. Abstract CSS artwork has no external image licensing dependency. Google Fonts is optional; system fallbacks work without it. No form submission is included. Review facts, visual quality and accessibility before publishing.
